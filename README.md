# 读数统计（cpp-build-run）

C11 实践项目：从标准输入读入一批传感器读数，按严格输出契约打印统计摘要（count / sum / min / max）。重点是把「编辑 → 编译 → 运行 → 比对 → 提交」这条闭环走通，并验证程序在完整工具链下的行为。

## 题目描述

**输入**

- 第一行：整数 `n`（`1 <= n <= 10000`），读数个数。
- 第二行：`n` 个整数，用空格分隔，每个在闭区间 `[-1000, 1000]`。

**输出**

向标准输出恰好输出 4 行（`=` 两边不要有空格）：

```text
count=<n>
sum=<所有读数之和>
min=<最小读数>
max=<最大读数>
```

程序必须以退出码 0 结束。`sum` 在 32 位 `int` 范围内。

## 构建与运行

```bash
# 编译（-Wall -Wextra 用于提前发现问题；判题机使用不带告警开关的 gcc -std=c11）
gcc -std=c11 -Wall -Wextra -o main src/main.c

# 运行
./main < samples/01-mixed.in

# 与期望输出逐字符比对：无输出且退出码为 0 表示一致
diff <(./main < samples/01-mixed.in) samples/01-mixed.out
echo $?
```

## 实现要点

- **流式读入，不使用数组**：读一个数就更新一次统计量，空间开销与 `n` 无关。
- **`min` / `max` 用第一个读到的数初始化**，而不是 0。0 未必出现在输入里：若用 0 初始化，全正数输入会让 `min` 一直卡在 0，全负数输入会让 `max` 一直卡在 0。因此先读第一个读数并同时赋给 `sum`、`min`、`max`，循环从第二个读数开始。
- **每次 `scanf` 都检查返回值**：返回值不等于 1 表示没有成功读入，此时以非零退出码退出，绝不拿未读入的值参与统计。
- **输出严格对齐契约**：恰好 4 行、`=` 两边无空格、每行以换行结尾、退出码 0。

## 测试

| 用例 | 覆盖点 | 结果 |
| --- | --- | --- |
| 01-mixed | 正负混合 | 通过 |
