# 读数统计（cpp-build-run）

C11 实践项目：从标准输入读入一批传感器读数，按严格输出契约打印统计摘要（count / sum / min / max）。重点是把「编辑 → 编译 → 运行 → 比对 → 提交」这条闭环走通。

## 题目描述

**输入**

- 第一行：整数 `n`（`1 <= n <= 10000`），读数个数。
- 第二行：`n` 个整数，用空格分隔，每个在闭区间 `[-1000, 1000]`。

**输出**

向标准输出恰好输出 4 行（`=` 两边不要有空格）：

```text
count=<n>
sum=<所有读数之和>
min=<最小读数>
max=<最大读数>
```

程序必须以退出码 0 结束。`sum` 在 32 位 `int` 范围内。
